# ALVOXIS WORLD

Браузерная песочница «симулятор бога» в пиксельном ретро-стиле (визуальный стиль и формат —
по мотивам [EarthPlay](https://github.com/KaveeshRamsarran/EarthPlay)), где у каждого существа
есть собственный искусственный интеллект (идеи — из
[LIFE / life-simulation](https://github.com/dominikvytisk/life-simulation)).

Код написан с нуля на чистом HTML/CSS/JavaScript, без сборки и зависимостей.

## Как запустить

Открой `index.html` в браузере (или `python3 -m http.server` в папке проекта и зайди на `http://localhost:8000`).

## Что есть

- **Мир**: процедурная генерация (континент, остров, архипелаг, озёра), 11 типов местности,
  растения растут и выедаются, падаль гниёт, пожары распространяются, лава остывает,
  пепел зарастает травой, трава — лесом. Смена дня и ночи, времена года.
- **Существа с ИИ** — у каждого своя нейросеть:
  - 38 входов (зрение еды/мяса/преград, ближайший сородич и ближайший чужак, боль, награда,
    память, слух, свет, холод, яд в теле…) → скрытый рекуррентный слой → 11 действий
    (движение, поворот, есть, атаковать, размножаться, отдыхать, рывок, делиться, подражать, звать);
  - **врождённые веса** (гены) + **выученные за жизнь** (Хеббовское обучение с подкреплением:
    еда — награда, боль — наказание). Выученное не наследуется;
  - **эпизодическая память мест**: где было хорошо и где опасно;
  - **подражание** сытым сородичам (культура) и **звуковые сигналы**;
  - **эволюция**: геном из 15 генов (размер, скорость, зрение, хищность, размер мозга, обучаемость,
    память, плавание, морозостойкость, иммунитет, долголетие, частота мутаций…), скрещивание
    и мутации генов и мозга;
  - **видообразование**: если потомки слишком отличаются от предков — появляется новый вид.
- **Инструменты бога**: кисти ландшафта, заселение готовых видов и конструктор своего вида,
  метеорит, молния, пожар, дождь, засуха, чума, благословение, мутаген, «мудрость», землетрясение.
- **Инспектор существа**: мысли, живая нейросеть, геном, воспоминания на карте, слежение камерой.
- **Статистика**: графики популяций, список видов (с предками), летопись мира.
- **Сохранение** в браузере (IndexedDB).

## Управление

- Мышь: левая кнопка — инструмент, правая/средняя — двигать карту, колесо — масштаб.
- Телефон: один палец — инструмент (с «Рукой» — двигать карту), два пальца — масштаб.
- Клавиши: пробел — пауза, 1–5 — скорость, WASD/стрелки — камера, Esc — снять выбор.

| `js/render.js` | Отрисовка и эффекты |
| `js/ui.js` | Интерфейс, инспектор, статистика |
